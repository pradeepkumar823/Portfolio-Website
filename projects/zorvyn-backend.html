Zorvyn Backend

Secure REST API for a Multi-Role Financial Dashboard

Java 17 Spring Boot 3.4.3 Spring Security 6 JJWT (0.11.5) H2 Database
View on GitHub

Project Overview

Zorvyn Backend is a production-ready financial dashboard REST API engineered to serve multi-role users. Designed using clean layered architecture patterns in Spring Boot, the API provides high performance, validation, and advanced security constraints.

It integrates Spring Security 6 with JJWT to facilitate secure login, token-based requests, and user registration. Role-Based Access Control (RBAC) separates actions for Admins, Users, Analysts, and Viewers, allowing granular access to financial records and summary reports.

Key Features

JWT Authentication

Token-based user login and registration utilizing JJWT signature verification and filter-level interceptors.

Role-Based Security

Method-level protection (@PreAuthorize) checking roles (ADMIN, USER, ANALYST, VIEWER) for each request handler.

Dashboard Calculations

Aggregated queries for income summaries, category breakdowns, monthly trends, and recent transaction lists.

Soft-Delete System

Safely handles deletion of financial records via boolean status filtering in custom JPQL repositories.

Pre-Seeded Data

Development convenience featuring automatically seeded dummy data into an accessible H2 in-memory console.

Structured Validation

Robust Jakarta Bean Validation constraints coupled with a GlobalExceptionHandler for detailed error JSON.
